# Cadastro Técnico Estadual (CTE) - Paraíba

## Descrição do Projeto
Este projeto implementa uma interface web para o sistema de Cadastro Técnico Estadual de Atividades Potencialmente Poluidoras e/ou Utilizadoras de Recursos Ambientais (CTE) para o estado da Paraíba, desenvolvido para a SUDEMA (Superintendência de Administração do Meio Ambiente).

O sistema permite a identificação e cadastro de pessoas físicas e jurídicas sob controle e fiscalização ambiental, conforme regulamentações ambientais aplicáveis.

## Tecnologias Utilizadas

### Frontend
- **HTML5** - Estruturação das páginas web
- **CSS3** - Estilização dos componentes e layout responsivo
- **Bootstrap 4.5.2** - Framework CSS para design responsivo e componentes pré-construídos
- **Google Fonts** - Fonte Source Sans Pro para tipografia consistente

### Recursos Visuais
- Imagens WebP e PNG otimizadas
- Ícones SVG para melhor escalabilidade
- Efeitos de blur com CSS (backdrop-filter)

### Design
- Layout responsivo adaptado para diferentes tamanhos de tela
- Paleta de cores institucional com foco nas cores:
  - Azul institucional (#183884)
  - Branco (#FFFFFF)
  - Cinza escuro (#212529)
  - Ciano (#0DCAF0)
- Tipografia clara com hierarquia visual definida usando a fonte Source Sans Pro

## Páginas do Sistema

### 1. Página Inicial (index.html)
Apresenta uma introdução ao sistema com:
- Seção informativa sobre o CTE
- Opções de acesso para usuários já cadastrados
- Opções de cadastro para novos usuários (pessoas físicas e jurídicas)

### 2. Informativos (informativos.html)
Contém diversos tópicos informativos sobre o CTE, organizados em formato de cards, incluindo:
- O que são os CTEs
- Base legal
- Quem deve se cadastrar
- Certificado de Regularidade
- Glossário e legislação

### 3. Páginas de Conteúdo Específico (cte.html)
Páginas detalhadas sobre tópicos específicos do CTE, com explicações aprofundadas sobre cada tema.

## Desenvolvimento
O projeto foi desenvolvido utilizando práticas modernas de desenvolvimento web front-end, com foco em acessibilidade e experiência do usuário.
